CONFIGURACIÓN DE RESEÑAS

La página ya incluye el SDK modular de Firebase y Firestore para la colección "reviews".

Para que las reseñas funcionen públicamente, en Firebase Console ve a Firestore Database > Rules y configura reglas que permitan lectura pública y creación pública con validación. Ejemplo inicial (revísalo antes de publicar):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /reviews/{reviewId} {
      allow read: if true;
      allow create: if request.resource.data.name is string
        && request.resource.data.name.size() >= 1
        && request.resource.data.name.size() <= 40
        && request.resource.data.message is string
        && request.resource.data.message.size() >= 1
        && request.resource.data.message.size() <= 280
        && request.resource.data.rating is int
        && request.resource.data.rating >= 1
        && request.resource.data.rating <= 5;
      allow update, delete: if false;
    }
  }
}

Nota: estas reglas permiten que cualquiera publique una reseña. Si quieres evitar spam o abuso, el siguiente paso recomendable es añadir Firebase Authentication y/o App Check, además de límites antispam.
